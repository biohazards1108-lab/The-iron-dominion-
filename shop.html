🛒 Store Provider

PLANNED PROVIDER

Tebex

The production store is planned around Tebex because it provides a dedicated gaming-store platform with payment, fraud/chargeback, and compliance tooling. The actual Minecraft integration will only be enabled after compatibility with the legacy Tekkit/Cauldron environment is verified.

No payment form is embedded on this website. Checkout will remain on the provider's secured store.

Learn About Tebex

◆ Dominion Tokens

Dominion Tokens are a separate in-game reward currency. Voting rewards and future server systems will be handled server-side so the browser cannot manufacture tokens.

Security: the website will never accept a player-supplied token balance, payment confirmation, or vote result as proof of entitlement.
