## Build / dependency policy
- Paper runtime must be Java 25 and Paper 26.3 build 256.
- Any new Iron Dominion plugin must compile with JDK 25, `--release 25`, and Paper API `io.papermc.paper:paper-api:26.3.build.256-stable`.
- Existing `minecraft-plugin/`, `npc-plugin/`, and `dominion-tokens/` source projects still target CraftBukkit 1.6.4 and Java 6/8. They are excluded from this release and are not compatible.
- Third-party plugin JARs are distributed by their publishers; the compatibility register links to official sources and does not repackage them.
