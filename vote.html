◆ How Token Rewards Work

  1. You vote using an official server-list link.
  2. The voting service sends a server-side vote event.
  3. The Iron Dominion reward system verifies the event and prevents duplicate/replayed rewards.
  4. The player receives the configured Dominion Token reward in game.
  5. The reward is logged so support can investigate missing rewards without trusting browser-side claims.
Security rule: the website will never decide that a vote happened or award tokens from a client-side button. Vote verification and token grants must happen server-side.
