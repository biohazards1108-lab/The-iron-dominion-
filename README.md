# Iron Dominion

Official website repository for **Iron Dominion**, a Tekkit 1.6.4 survival server focused on technology, exploration, progression, trade, and player-built settlements.

## Website

The site is a static frontend designed to be deployed through GitHub Pages, Vercel, or another static host.

## Current architecture

- `index.html` — public landing page
- `join.html` — connection and onboarding guide
- `ranks.html` — rank progression overview
- `economy.html` — Dominion Credits and Dominion Tokens overview
- `leaderboard.html` — leaderboard frontend
- `shop.html` — planned rewards/store area
- `rules.html` — server rules
- `css/style.css` — shared responsive styling
- `js/server.js` — server-status frontend
- `js/economy.js` — economy UI helpers
- `js/leaderboard.js` — leaderboard UI helpers
- `api/server.json` — placeholder status feed

## Important data policy

The website does **not** fabricate live player counts, TPS, balances, rankings, or purchases. Until a secure server-side API is connected, unavailable data is displayed as unavailable.

The public `api/server.json` file is only a placeholder and must not be treated as a live source of truth.

## Planned backend integration

The next backend phase should provide authenticated, read-only endpoints for:

1. server online status and player count
2. TPS/performance metrics
3. player economy balances
4. Dominion Token balances
5. leaderboard data
6. verified store transactions

These values should be generated by the Minecraft server or a trusted server-side service, not manually edited in the website repository.

## Development principle

Iron Dominion follows a design-first approach: implement real systems before advertising them as live features. Website copy should stay synchronized with the actual Minecraft server configuration.
