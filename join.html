🌐 CONNECTION DETAILS

Connect from Minecraft Bedrock

On your device, open Minecraft → Play → Servers → Add Server. Enter the server name you prefer, then copy the address and port below into their matching fields.

Having trouble joining?

1. Check your version

Make sure Minecraft Bedrock is updated and compatible with the server version. A version mismatch can prevent a connection.

2. Check server reachability

If the status checker says unavailable, that is not definitive proof the server is offline. Confirm the server is started in Akliz and check Discord for maintenance notices.

3. Try the details again

Carefully verify the hostname and port. If it still fails, note the exact Minecraft error and your device/client version.

4. Get help

Share the error in the official community so we can investigate without guessing.
